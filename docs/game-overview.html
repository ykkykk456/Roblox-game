ผู้เล่นทำอะไรในแต่ละรอบ

วงนี้คือหัวใจของเกม ฟีเจอร์ใหม่ทุกอันต้องตอบได้ว่าช่วยเสริมขั้นไหนในวงนี้

4ป้อมยิงมอนเล็กมอนเดินผ่านตลอด ได้เงินตั้งแต่นาทีแรก แม้ AFK

6รับรางวัลขั้นต่ำทุกคน + ตามดาเมจ · ตั๋วกาชา · อุปกรณ์แต่งปืน

ระบบทั้งหมดและสถานะ

ป้อม

มีแล้ว
  • คนละ 1 ป้อม วางรอบวงกลางแมพให้อัตโนมัติ
  • ยิงเอง: บอสก่อน ถ้าไม่มีบอสยิงมอนที่ใกล้สุด
  • อัปเลเวลด้วยเงิน ดาเมจและอัตรายิงเพิ่ม หน้าตาไม่เปลี่ยน

มอนเล็ก

มีแล้ว
  • เกิดที่ขอบแมพ เดินผ่านกลางไปอีกฝั่งตลอดเวลา
  • ตายแล้วแบ่งเงินตามสัดส่วนดาเมจ
  • ตอนนี้เป็นลูกบอล ยังไม่มีโมเดล

บอสตามเวลา + ตารางดาเมจ

มีแล้ว
  • แถบ HP และเวลาถอยหลังบนจอ
  • ตาราง 5 อันดับดาเมจ
  • รางวัล = ขั้นต่ำทุกคน + ตามดาเมจ · หนี = เงินลด ไม่มีตั๋ว

สกิลป้อม + กาชา

มีแล้ว
  • 5 สกิล 4 ระดับความหายาก โอกาส 60 / 28 / 10 / 2% แสดงบนหน้ากาชา
  • ได้ถาวร ซ้ำ = วัตถุดิบอัปขั้น (สูงสุดขั้น 5)
  • ใส่ได้ 1 สกิล กดใช้เองตอนสู้

Friend Boost

มีแล้ว
  • +10% รายได้และดาเมจบอสต่อเพื่อน 1 คน
  • สูงสุด +40% นับเฉพาะเพื่อนในเซิร์ฟเดียวกัน

HUD + ตั้งค่า + เซฟข้อมูล

มีแล้ว
  • เหรียญ เมนู FPS · หน้าตั้งค่าเสียง ภาพ มุมกล้อง
  • เซฟเงิน เลเวลป้อม ตั๋ว สกิล และไม่เซฟทับเมื่อโหลดพลาด

เก็บของ + กระเป๋า

ถัดไป
  • เดินชนเก็บในทุ่ง ถือได้จำกัด อัปกระเป๋าได้
  • ของหายากเกิดสุ่ม

ขายของ

ถัดไป
  • เดินทับจุดขายที่ฐาน ได้เงิน

บ้าน idle

ถัดไป
  • ผลิตเงินอัตโนมัติ อัปด้วยเงินและของอัปบ้านจากบอส

กระสุนพิเศษ

ถัดไป
  • เอาของใส่ลังข้างป้อม ยิงตอนบอสมา
  • ไฟ / น้ำแข็ง / ระเบิด ผลต่างกัน · แม็กกาซีนอัปได้

อุปกรณ์แต่งปืน

ภายหลัง
  • 4 ช่อง: ลำกล้อง (ดาเมจ) · กลไกยิง (อัตรายิง) · ศูนย์เล็ง (คริ) · แกนพลัง (ผลพิเศษ)
  • 5 ระดับ ธรรมดา → ตำนาน และเปลี่ยนหน้าตาป้อม

เรื่องตอนนี้ใครตัดสิน
ธีมและหน้าตาของโลกมีแค่แนวภาพบล็อกสีเรียบจากสเก็ตช์ ยังไม่มีธีมเรื่องราวเจ้าของเกม

จำนวนผู้เล่นต่อเซิร์ฟผังแมพออกแบบไว้ 8 ฐาน · โค้ดตอนนี้รองรับป้อม 12 จุดเจ้าของเกม
ตัวเลขทั้งหมด (เวลาบอส รางวัล ราคา โอกาสดรอป)ใช้ค่าทดสอบ ติดป้าย [Proposed] ทุกค่าฝ่ายเศรษฐกิจ + เจ้าของเกม
