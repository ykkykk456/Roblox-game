- ทุกตัวใช้ขั้นตอนเดียวกับโรบอท: หาโมเดลชื่อยืดหยุ่น · ย้ายจาก Workspace ไป ServerStorage/Bosses ตอนเริ่ม · เลือก HumanoidRootPart ที่ต่อมากสุดแล้วยึด · คงการหมุนเดิม · วัดเท้า · ปิดสถานะ Humanoid

## กระต่าย: แก้เท้าลอยในท่า Motion Capture — เพิ่ม 2026-09-29
สาเหตุ: กล้องประเมินท่าโดยยึดสะโพก ตอนย่อ/งอเข่ามันกะว่าสะโพกลงต่ำน้อยกว่าจริง → ขางอแล้วเท้าลอย
วิธีแก้ = เลื่อน "ข้อต่อราก" (HumanoidRootPart → LowerTorso) ลงทุก Keyframe ให้เท้าที่ต่ำสุดแตะพื้นอ้างอิง (ไม่แตะโมเดล/ข้อต่อ แก้แค่ข้อมูลท่า)

### ถ่ายคลิปใหม่ให้ลอยน้อยตั้งแต่แรก
- กล้องตั้งขาตั้ง (ห้ามถือ) · สูงระดับอก ~1 ม. · กล้องตั้งตรงไม่เอียง
- ห่าง 3–4 ม. · ถ่ายตรงหน้า หรือเฉียง 30–45°
- เห็นทั้งตัว **และพื้นใต้เท้า** ตลอดคลิป
- เริ่มและจบด้วยการยืนตรงนิ่ง ~1 วิ (Keyframe แรก = พื้นอ้างอิงของสคริปต์)
- ย่อตัวช้า ๆ · ใส่เสื้อผ้าพอดีตัว สีตัดกับฉากหลัง · แสงสม่ำเสมอ · ในภาพมีคนเดียว
- คลิปสั้นกว่า 15 วิ · ห้ามซูม/แพนกล้องระหว่างถ่าย

### รันสคริปต์แก้เท้าลอย `tools/studio/fix_foot_float.lua`
1. กด Stop (โหมดแก้งาน ห้ามตอน Play) → View → Command Bar → วางทั้งไฟล์ → Enter
2. รอบแรก `DRY_RUN = true` = ดูตารางใน Output อย่างเดียว (ลอยก่อน/เลื่อน/ลอยหลัง) ไม่เปลี่ยนอะไร
3. ตัวเลขดี → ตั้ง `DRY_RUN = false` รันซ้ำ → ได้ท่า `Idle_FootFix` ใน `ServerStorage > RBX_ANIMSAVES > Boss_rabbit` (ท่าเดิมไม่ถูกแตะ)
4. Animation Editor → Load `Idle_FootFix` → เช็ก → Publish → ใส่เลขใหม่ที่ `Combat.luau` (แถว Boss_rabbit → `Animations.Idle`)
5. สำรองแล้วลบ `RBX_ANIMSAVES` ก่อน Play (เหมือนขั้นตอนของโรบอทด้านบน)
- ค่าตั้ง: `SOURCE_NAME` = ใช้ท่าที่ Save ไว้แทนเลข ID · `REFERENCE` = `"first"` (Keyframe แรก) / `"lowest"` · `MODE` = `"both"` / `"lowerOnly"`
- ถ้าท่าเป็น CurveAnimation แล้วสคริปต์แก้ไม่ได้: Animation Editor → ⋯ → Import → From Roblox (เลข ID) → Save ชื่อใหม่ โดยไม่เปิด Curve Editor → ใส่ชื่อนั้นใน `SOURCE_NAME`
