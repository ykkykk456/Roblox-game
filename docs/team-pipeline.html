PRINCIPLES.md

กฎเหล็ก 3 ข้อ

ใช้กับทุกบทบาท ทุกงาน ยกเว้นได้ก็ต่อเมื่อ CEO ตัดสินเท่านั้น

1

Server Authority

Server คือความจริงแหล่งเดียว Client ไม่น่าเชื่อถือเสมอ

  • Client ส่งเจตนา Server คำนวณผล
  • ทุก Remote ผ่าน Guard + ตรวจช่วงค่า/สิทธิ์
  • เก็บเงิน/ไอเทมเป็นความจริงที่ Client
  • วางความลับใน shared/client
2

Data Safety

ข้อมูลต้องไม่เสีย แม้โหลดล้มเหลวหรือผิดรูปแบบ

  • DataStore ครอบ pcall + retry
  • เปลี่ยน schema = เพิ่ม VERSION + migration
  • บันทึกทับเมื่อโหลดไม่สำเร็จ
  • เรียก DataStore นอก PlayerData
3

Evidence

ข้อเท็จจริงสำคัญเรื่อง Roblox ต้องติดป้ายหลักฐาน

  • ไม่แน่ใจ = [Unverified]
  • ข้อเสนอติด [Proposed] รออนุมัติ
  • ยกระดับป้ายโดยไม่มีหลักฐาน
  • ใช้ [Assumed] เป็นฐานงาน Security/Data

ข้อจำกัดบังคับ

  • ห้ามใช้ MCP ทุกรูปแบบ ถ้างานดูเหมือนต้องใช้ ให้ STOP and REPORT
  • พัฒนาเกม Roblox เท่านั้น
  • ตัวเลขราคา/Balance ไม่ตัดสินเอง ใช้ src/shared/Config/

STOP and REPORT

เมื่อข้อกำหนดขัดกัน คลุมเครือ หรือต้องละเมิดกฎ Claude ต้องหยุดและรายงานขึ้นไปที่ Gemini/CEO ห้ามเดาเอง ถ้า Handoff ไม่ครบก็ใช้กฎนี้เช่นกัน

ป้ายที่เห็นในโค้ดและรายงาน

ป้ายหลักฐาน 5 แบบ

ป้ายความหมายใช้เป็นข้อเท็จจริงได้ไหม
[Verified]ยืนยันจากเอกสาร Roblox ทางการหรือผลทดสอบจริงได้
[Inferred]สรุปอย่างมีเหตุผลจากหลักฐานที่ยืนยันแล้วใช้ระวัง ต้องบอกเหตุผล
[Assumed]สมมติฐานชั่วคราวเพื่อไปต่อไม่ได้ ต้องตรวจทีหลัง
[Proposed]ข้อเสนอที่ยังไม่อนุมัติยังไม่ใช่การตัดสินใจ
[Unverified]ยังไม่มีหลักฐาน หรือไม่รู้แหล่งที่มาไม่ได้
