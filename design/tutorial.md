# Feature Spec — Tutorial ฝึกสอนตอนเข้าเกม (2026-10-01)

สถานะ: [Proposed] · ยังไม่ทดสอบใน Studio · ค่าตัวเลขอยู่ `src/shared/Config/Tutorial.luau`

## การตัดสินใจ (เจ้าของเกมให้ Claude ตัดสินเอง)
- **สอนเป็นขั้น ๆ แบบให้ลงมือทำ (learn by doing)** ไม่ใช่หน้าข้อความยาวทีเดียว
  เหตุผล: ผู้เล่น Roblox ส่วนใหญ่ (เด็ก/มือถือ) ข้ามการอ่านยาว · ขั้นสั้นที่ "กดแล้วเห็นผลทันที" จำได้ดีกว่าและไม่น่าเบื่อ
  แต่ละขั้น = ข้อความ 1 บรรทัด + ลูกศร/เส้นนำทางชี้จุดเดียว + ทำเสร็จไปขั้นถัดไปเอง (ไม่มีปุ่ม Next ให้กดข้าม)
- **บังคับทุกคน** (รวมผู้เล่นเก่า) · ทำครั้งเดียว บันทึกลงเซฟ · ทั้งหมดใช้เวลา ~1–2 นาที
- **ระหว่างฝึก:** ป้อมของผู้เล่นคนนั้นทำดาเมจบอสไม่ได้ · ปุ่มที่ไม่เกี่ยวกับขั้นปัจจุบันกดไม่ได้ (Server ปฏิเสธ) · ผู้เล่นคนอื่นเล่นตามปกติ
- **บอสมาระหว่างฝึก:** ปล่อยให้มาตามปกติ ยกเว้นตอนมีผู้เล่นอยู่ขั้น "มอนฝึก" → เลื่อนบอสออกไปจนขั้นนั้นจบ (เลื่อนได้ไม่เกิน `MaxBossHold` วินาที กันบอสไม่มาเลย)
  ถ้าบอสมาแล้ว ผู้เล่นที่ยังฝึกอยู่ข้ามขั้นที่ต้องใช้มอน (เพราะมอนไม่เกิดตอนบอสอยู่) → ไปขั้นถัดไปที่ทำได้ แล้วกลับมาขั้นมอนหลังบอสจบ

## ขั้นตอน (5 ขั้น)
| # | id | ผู้เล่นเห็น | ต้องทำ | จบเมื่อ |
|---|---|---|---|---|
| 1 | ChooseElement | หน้าเลือกธาตุเปิดทันทีที่เข้าเกม (ปิดไม่ได้ระหว่างฝึก) · "เลือกธาตุให้ป้อมของคุณ!" | เลือกธาตุ | Element ≠ "" |
| 2 | WatchTurret | ลูกศรชี้ป้อมตัวเอง · "ป้อมของคุณยิงเองอัตโนมัติ — ดูมันจัดการมอน!" · มอนฝึก 3 ตัว (อ่อน) เดินมาตามเลนตัวเอง | ดู | มอนฝึกตายครบ (หรือหมดเวลา `WatchTimeout`) |
| 3 | UseSkill | ปุ่มสกิลกระพริบ + "กด Q (หรือปุ่มสกิล) ใช้สกิลธาตุ!" · มอนฝึก 2 ตัวเกิดให้เป็นเป้า · คูลดาวน์ถูกรีเซ็ตให้กดได้ทันที | ใช้สกิลสำเร็จ 1 ครั้ง | useSkill คืน true |
| 4 | Upgrade | ปุ่มอัปกระพริบ + "เก็บเงินจากมอนแล้ว — กด U อัปป้อมให้แรงขึ้น!" · เติมเหรียญให้พอค่าอัป 1 ครั้ง (ถ้าไม่พอ) | อัปป้อม 1 ครั้ง | upgrade คืน true |
| 5 | MeetBoss | เส้นนำทาง/ลำแสงชี้จุดเกิดบอส · "บอสยักษ์จะมาตรงนี้ทุก ~3 นาที! ตีให้แรงที่สุด = ได้เงิน + อุปกรณ์ (กด G ดู)" | ไม่ต้องทำ (อ่าน) | ครบ `ReadSeconds` วิ หรือกดปุ่ม "เข้าใจแล้ว!" |
จบ → ป้ายฉลอง "พร้อมลุย!" + โบนัสเหรียญ `RewardCoins` · TutorialDone = true · ปลดล็อกทุกอย่าง

- ลูกเล่น (ไม่เน้นสวย): ลูกศรเด้งขึ้นลงเหนือเป้า · ปุ่มที่ต้องกดกระพริบ/ขยาย · แถบความคืบหน้า "ขั้น 2/5" · เสียง/เอฟเฟกต์เล็ก ๆ ตอนผ่านขั้น
- มอนเลนตัวเอง (ปกติ) จะไม่เกิดจนกว่าผู้เล่นเลือกธาตุ · มอนฝึก = เกิดเฉพาะเลนผู้เล่นคนนั้น เลือดน้อย (`TrainingMonsterHp`)

## ข้อมูล
PlayerData v7 → v8: `TutorialStep = 1` (1..5, 6 = จบ) · `TutorialDone = false` · migration: ทุกคน false (บังคับฝึกทุกคน)
Mirror Attribute: `TutorialStep`, `TutorialDone`

## สิทธิ์ (Server เป็นคนตัดสิน)
- ยังไม่จบ: `BossService.damage` จากป้อมคนนี้ = ไม่นับ (กรองที่ TurretElementService.damageBoss ไม่แตะไฟล์บอส)
- ยังไม่จบ: upgrade ได้เฉพาะขั้น 4 · useSkill ได้เฉพาะขั้น 3 · Gear/เปลี่ยนธาตุ (หลังเลือกแล้ว) ไม่ได้
- ความคืบหน้าขั้นเลื่อนที่ Server เท่านั้น (Client ไม่มี Remote "จบขั้น" ยกเว้นขั้น 5 กดเข้าใจแล้ว = Remote `TutorialAck` ที่ Server ตรวจว่าอยู่ขั้น 5 และผ่านไป ≥ `MinReadSeconds`)

## เกณฑ์ตรวจรับ
- [ ] เข้าเกม → หน้าเลือกธาตุเปิดเอง · มอนเลนตัวเองไม่เกิดจนเลือก
- [ ] ทำครบ 5 ขั้นได้ใน ~2 นาที · ข้ามขั้นไม่ได้ · กดปุ่มอื่นระหว่างฝึก ไม่มีผล
- [ ] ระหว่างฝึก ดาเมจบอสของคนนี้ = 0 · คนอื่นปกติ
- [ ] บอสไม่เกิดตอนมีคนอยู่ขั้นมอนฝึก (เลื่อนไม่เกิน MaxBossHold)
- [ ] ออกกลางคันแล้วเข้าใหม่ → ทำต่อจากขั้นเดิม · จบแล้วไม่ต้องฝึกซ้ำ
