# Design Brief — แมพหลุมอุกกาบาต

> ยืนยันโดยเจ้าของเกม 2026-09-25 · ได้จาก `/roblox-design-thinking`
> ภาพสเก็ตช์: `docs/map-sketch/crater-concepts.html` · ตัวเลขทุกตัวเป็น `[Proposed]` ค่าจริงอยู่ใน `src/shared/Config/`

## Persona `[Assumed]` (ยังไม่ได้สัมภาษณ์ผู้เล่นจริง)
- เด็ก 9–12 ปี เล่นมือถือ ต้องเข้าใจเร็ว ไม่ชอบอ่าน
- วัยรุ่น PC อยากติดท็อปดาเมจ
- คนเปิด AFK อยากได้ของโดยไม่โดนแย่ง

## Problem Statement
ผู้เล่นอายุ 9–25 ต้องการแมพที่ดูแล้วรู้ทันทีว่าเป็นเกมตีบอสด้วยป้อม (ไม่เหมือนเกมฟาร์ม) และทุกฐานได้โอกาสเท่ากัน

## ตัดสินแล้ว
| หัวข้อ | คำตัดสิน |
|---|---|
| แมพ | หลุมอุกกาบาต (แบบ A) |
| ผู้เล่น | 8 คนต่อเซิร์ฟ คนละ 1 ฐาน มีป้อมเริ่มต้น |
| กลางแมพ | หลุม = จุดบอสเกิดอย่างเดียว · ไม่มีเสาพลัง ไม่มีร้าน |
| บอสพิเศษ | ทั้งเซิร์ฟช่วยกันส่งของครบเป้าแล้วบอสพิเศษเกิด · คนไม่ส่งได้ของน้อยกว่าคนส่ง |
| ของที่เก็บ | **ในแอ่งกลางแมพ (จุดบอสเกิด)** ใช้ร่วมกัน แย่งกันเก็บ ของหายากให้สิทธิพิเศษ · ปิดตอนบอสมา (ยืนยัน 2026-09-26 แทนทุ่งวงแหวนรอบหลุม) |
| สวนหลังบ้าน | เป็นที่เกิดมอนตัวเล็ก/กลางของแต่ละฐาน |
| อัปเกรด | ป้ายอัปเกรดที่ฐานตัวเอง (ไม่มีร้านกลางแมพ) |
| จุดส่งของเรียกบอสพิเศษ | ที่ฐานตัวเอง (ยืนยัน 2026-09-25) |
| Prototype | สร้าง 1 ฐานก่อนเพื่อดูระบบ แล้วค่อยเพิ่มถึง 8 (`Map.BaseCount`) |
| ระยะยิงป้อม | ยังไม่ออกแบบ (ถ้าเป็นวงกลมจะยิงมอนฐานข้างๆ ได้) · ใช้ Range 60 เดิมไปก่อน |
| ข้อมูล | โครง PlayerData v4 (ด้านล่าง) |

## ผัง (หน่วย studs · กลางแมพ = 0,0)
| โซน | ขนาด/ตำแหน่ง |
|---|---|
| พื้น | **วงกลม** รัศมี 160 (ลดจาก 181 เมื่อ 2026-09-26) · ผิวบน Y = 1 · บล็อก 8×8 ผิว Studs สีสลับ (ไม่ต้องอัปโหลดภาพ) · สร้างจาก `tools/gen_map.py` → เห็นใน Studio ตอนแก้แมพ · ภาพผัง `docs/map-sketch/map-v2.png` |
| **แอ่งกลาง = จุดบอส + ที่เก็บของ** (ยืนยัน 2026-09-26) | รัศมี 40 · ขั้นบันไดเดินลงได้ทุกทิศ: 30–40 ลึก 1 · 18–30 ลึก 2 · 0–18 ลึก 3 · tag `LootZone` |
| บอส | ลอยกลางแอ่ง สูง 14 · **เตือน 10 วิก่อนมา → แอ่งปิด (ของหยุดเกิด) · บอสอยู่ = ผู้เล่นในแอ่งถูกย้ายขึ้นถนน** (`PitService`) |
| ถนนวงแหวน | รัศมี 40–52 บล็อกสีเข้ม รอบแอ่ง |
| ป้อมเริ่มต้น | ห่างกลาง 56 (8 จุด ทุก 45°) → ถึงบอสด้วย Range 60 เดิม (ระยะจริง ≈ 56.6) `[Inferred: คำนวณจาก HEAD_HEIGHT/Boss.Height ในโค้ด]` |
| ลานฐาน | 44 × 44 ห่างกลาง 80 · ขอบสีประจำผู้เล่น · บ้าน · แผ่นขาย · ลังกระสุน · ป้ายอัปเกรด · จุดส่งของเรียกบอสพิเศษ |
| สวนหลังบ้าน (มอน) | รูปพัด ±18° หลังฐาน รัศมี 104–140 · มอนเกิดในสวน แล้ว**เดินสุ่มไปมา**ในพื้นที่รูปพัด ±20° รัศมี 60–124 ของฐานตัวเอง ไม่เข้าลานฐาน/บ้าน · อยู่ครบ 90 วินาทีแล้วหายไป (ยืนยัน 2026-09-25 แทนทางมอนเดิม) |
| ขอบแมพ | กำแพงเตี้ยวงกลม + กำแพงใสกันตก · แนวต้นไม้ทรงกล่องสร้างมือเพิ่มได้ |

## กฎของระบบ (สำหรับ `/roblox-feature`)
1. **มอนสวนหลังบ้าน**: 2 ขนาด (เล็ก = เร็ว HP น้อย · กลาง = ช้า HP มาก เงินมากกว่า) เกิดในสวนของฐานนั้นเท่านั้น → ทุกฐานได้มอนเท่ากัน · ฐานที่ไม่มีเจ้าของไม่เกิดมอน `[Proposed]`
2. **แอ่งเก็บของ**: ของเกิดสุ่มจุดบนบล็อก tag `LootZone` ในแอ่งกลาง เฉพาะตอน `PitService.isOpen()` · ใครชนก่อนได้ (Server ตัดสินด้วยระยะจริง ห้ามเชื่อ Client) · ของหายากให้สิทธิพิเศษชั่วคราว (ชนิด/ระยะเวลา → `/roblox-economy`)
3. **บอสพิเศษ**: เกจรวมเซิร์ฟ · ส่งของที่จุดส่งของในฐานตัวเอง → Server นับให้ทั้งเซิร์ฟ + นับแยกรายคน · ครบเป้า → บอสพิเศษพุ่งลงหลุม · รางวัล = ขั้นต่ำทุกคนที่มีดาเมจ + โบนัสตามสัดส่วนของที่ส่ง · ยอดส่งรายคนเป็นข้อมูลรอบเดียว **ไม่บันทึกลง DataStore**
4. **บอสมา**: ฟ้ามืด + วงเงาในหลุม 10 วินาทีก่อนบอสลง (เตือนทุกคนพร้อมกัน)

## โครงข้อมูล PlayerData v4 (ยืนยันแล้ว)
```lua
-- v3 เดิม (ห้ามเปลี่ยนชื่อ/ลบ)
Coins, TurretLevel, GachaTickets, Skills, EquippedSkill
-- v4 ใหม่
Upgrades = { Bag = 1, Magazine = 1, House = 1, Speed = 1 }, -- เลเวล ไม่ใช่ค่าพลัง
Gear = {},                    -- ["<ช่อง>_<ระดับ>"] = จำนวน เช่น Barrel_Rare = 2
Rebirths = 0,
LastSeen = 0,                 -- os.time() ฝั่ง Server (เงิน idle ตอนออฟไลน์ ต้องมีเพดาน)
Login = { Day = 0, Streak = 0 } -- Day = เลขวัน UTC
```

## ⚠️ เช็กก่อนเปิดระบบที่เกี่ยวกับข้อมูล
- ขายตั๋วด้วย Robux → `ProcessReceipt` บันทึกสำเร็จก่อนคืน `PurchaseGranted` + จำ PurchaseId
- เปิดแลกเปลี่ยนอุปกรณ์ → ต้องมี session lock ก่อน
- เพิ่ม field ใหม่ → `DEFAULT` + `VERSION` + `MIGRATIONS` ครบทุกครั้ง
- ทดสอบใน Studio → แยกชื่อ DataStore จากเกมจริง

## ยังเปิดอยู่
- ระยะยิงป้อม: ออกแบบใหม่ไม่ให้แย่งมอนฐานข้างๆ (ตอนนี้มีฐานเดียวจึงยังไม่เจอปัญหา)
- ชนิดสิทธิพิเศษจากของหายาก และตัวเลขทั้งหมด → `/roblox-economy`
- ผังนี้ยังไม่ได้เพลย์เทสต์ (แผนทดสอบใน `docs/map-sketch/crater-concepts.html`)
