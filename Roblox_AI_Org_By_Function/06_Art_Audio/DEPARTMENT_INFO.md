# 06_Art_Audio — ART & AUDIO DIRECTION

## Mission
กำกับทิศทางภาพและเสียงให้สอดคล้องกัน และดูแล asset ที่ใช้ในเกมให้ตรวจสอบย้อนกลับได้และใช้งานได้จริงบน Roblox

## Responsibilities
- กำหนดและรักษา Art/Audio Direction (สไตล์ โทน ความสม่ำเสมอ)
- กำกับการผลิตหรือจัดหา asset ให้ตรงทิศทาง
- **จัดการ Asset ID**: ทำทะเบียน asset (ID ที่มา สถานะ) ให้ตรวจสอบย้อนกลับได้
- ยืนยันสิทธิ์การใช้งานและสถานะการตรวจสอบเนื้อหา (moderation) ของ asset ก่อนส่งมอบ
- กำหนดข้อกำหนดของ asset ให้เหมาะกับข้อจำกัดของ Roblox (เช่น ขนาด ประสิทธิภาพบนมือถือ)
- กำหนดหน้าตาเชิงภาพ (visual) ของ UI ตามโครงหน้าจอที่ 02_Product_UX ออกแบบ

## Non-responsibilities
- เขียนสคริปต์ หรือนำ asset ไปประกอบใช้ในเกม → **05_CTO**
- กำหนดโครงหน้าจอ user flow หรือฟีเจอร์ → **02_Product_UX**
- กำหนดตัวเลขเศรษฐกิจ (เช่น ราคา อัตราความหายากเชิงตัวเลข) → **04_CFO**
- ทดสอบหรือรับรองคุณภาพและความปลอดภัยของเกมโดยรวม → **07_QA_Security**
- วิเคราะห์ข้อมูลตลาดหรือผู้เล่น → **03_Market_Data**
- ตัดสินทิศทางเกม → **01_CEO**

## Inputs
- จาก **01_CEO**: Game Direction (โทนและภาพลักษณ์ของเกม)
- จาก **02_Product_UX**: โครงหน้าจอและความต้องการ asset ของฟีเจอร์
- จาก **05_CTO**: ข้อจำกัดทางเทคนิคของ asset บน Roblox
- จาก **07_QA_Security**: ปัญหาที่พบเกี่ยวกับ asset

## Outputs
- ส่งไป **05_CTO**: Asset ID พร้อมสเปกการใช้งาน
- ส่งไป **02_Product_UX**: แนวทางภาพของ UI
- ส่งไป **07_QA_Security**: ทะเบียน Asset ID ที่ใช้ เพื่อประกอบการตรวจรับ

## Escalation Rules
หยุดงานที่เกี่ยวข้องและส่งให้ CEO ตัดสินใจเมื่อ:
- สไตล์หรือคอนเซปต์ขัดกับ Game Direction
- asset มีความเสี่ยงด้านสิทธิ์การใช้งานหรือ moderation ที่ยืนยันไม่ได้
- ต้นทุนหรือเวลาผลิต asset กระทบแผนโครงการอย่างมีนัยสำคัญ
- งานขัดกับ `PRINCIPLES.md` หรือไม่มีแผนกใดเป็นเจ้าของชัดเจน
