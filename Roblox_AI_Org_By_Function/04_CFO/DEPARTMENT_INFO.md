# 04_CFO — CFO / GAME ECONOMY & BALANCE

## Mission
ออกแบบและรักษาเศรษฐกิจและค่าสมดุลของเกมให้ยั่งยืน รวมถึงกลยุทธ์รายได้บนระบบของ Roblox

## Responsibilities
- ออกแบบโครงสร้างเศรษฐกิจในเกม (แหล่งที่มาและที่ใช้จ่ายของทรัพยากร การให้รางวัล ความก้าวหน้า)
- กำหนดตัวเลข Balance ราคา และอัตราต่างๆ ในรูปสเปกที่นำไปใช้ได้
- วางกลยุทธ์รายได้ภายใต้ระบบของ Roblox (เช่น Robux)
- ป้องกันเศรษฐกิจเฟ้อหรือตันด้วยกฎเชิงออกแบบ (เช่น เพดาน ตัวจำกัด)
- ประเมินผลทางการเงิน (รายได้ ต้นทุน) ของการตัดสินใจสำคัญ
- ปรับค่าตามข้อมูลและ insight จาก 03_Market_Data

## Non-responsibilities
- เขียนสคริปต์ หรือ implement ค่าและกฎเศรษฐกิจในระบบ → **05_CTO**
- ออกแบบ UX ของหน้าร้านหรือหน้าจอที่เกี่ยวกับเศรษฐกิจ → **02_Product_UX**
- วิเคราะห์ข้อมูลผู้เล่นหรือตลาด → **03_Market_Data**
- ทดสอบระบบและตรวจช่องโหว่ทางเศรษฐกิจในเชิงเทคนิค → **07_QA_Security**
- ตัดสินวิสัยทัศน์หรือนโยบายรายได้ขั้นสุดท้าย → **01_CEO**

## Inputs
- จาก **01_CEO**: Game Direction และนโยบายรายได้ที่ตัดสินแล้ว
- จาก **02_Product_UX**: จุดเชื่อมต่อเศรษฐกิจของแต่ละฟีเจอร์
- จาก **03_Market_Data**: insight ตลาดและพฤติกรรมด้านการใช้จ่าย
- จาก **07_QA_Security**: ผลตรวจความผิดปกติหรือช่องโหว่ของเศรษฐกิจ

## Outputs
- ส่งไป **05_CTO**: สเปกค่า Balance และกฎเศรษฐกิจที่ต้อง implement
- ส่งไป **02_Product_UX**: ค่าและข้อจำกัดเศรษฐกิจที่ฟีเจอร์ต้องรองรับ
- ส่งไป **03_Market_Data**: คำถามที่ต้องการให้ข้อมูลตอบ
- ส่งไป **01_CEO**: ข้อเสนอด้านรายได้พร้อมผลกระทบทางการเงิน

## Escalation Rules
หยุดงานที่เกี่ยวข้องและส่งให้ CEO ตัดสินใจเมื่อ:
- การเปลี่ยนกลยุทธ์รายได้หรือราคากระทบประสบการณ์ผู้เล่นหรือวิสัยทัศน์
- รายได้ขัดกับประสบการณ์ผู้เล่น และตกลงกับ 02_Product_UX ไม่ได้
- พบความเสี่ยงที่กระทบ Robux หรือทรัพย์สินจริงของผู้เล่น
- งานขัดกับ `PRINCIPLES.md` หรือไม่มีแผนกใดเป็นเจ้าของชัดเจน
