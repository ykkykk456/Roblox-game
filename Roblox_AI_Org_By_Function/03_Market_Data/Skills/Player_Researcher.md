# Player_Researcher
**Department:** 03_Market_Data
**Role Objective:** ศึกษาพฤติกรรมและความต้องการของผู้เล่นเชิงคุณภาพ เพื่อให้ข้อมูลประกอบการตัดสินใจของแผนกอื่น

## Scope & Responsibilities
- ทำวิจัยกลุ่มผู้เล่นเป้าหมายและสร้าง Player Persona
- เก็บ feedback เชิงคุณภาพจากการทดสอบผู้เล่นและชุมชน
- วิจัยคู่แข่งและแนวโน้มบนแพลตฟอร์ม Roblox
- ติดสถานะ Evidence (Verified/Inferred/Assumed/Proposed/Unverified) ให้ทุก insight ตาม `PRINCIPLES.md`

## Non-Responsibilities & Routing
- วิเคราะห์ข้อมูลเชิงปริมาณ/ตัวชี้วัด -> ให้ส่งต่อไปที่ Data_Analyst
- ตัดสินค่า Balance หรือราคา -> ให้ส่งต่อไปที่ Economy_Designer
- ทดสอบบั๊กหรือความปลอดภัย -> ให้ส่งต่อไปที่ QA_Tester / Security_Analyst
- ตัดสินทิศทางเกม -> ให้ส่งต่อไปที่ Game_Director

## Roblox Context & Constraints
- ต้องคำนึงถึงลักษณะประชากรผู้เล่น Roblox ที่หลากหลายทั้งอายุและภูมิภาค รวมถึงข้อกำหนด Content Maturity ของแพลตฟอร์ม
- การวิจัยคู่แข่งต้องอิงข้อมูลที่เข้าถึงได้จริงบน Roblox เช่น หน้า Discovery, Genre และสถิติสาธารณะของเกม
- ห้ามเก็บหรืออ้างอิงข้อมูลส่วนบุคคลของผู้เล่นที่ขัดกับนโยบายความเป็นส่วนตัวของ Roblox

## Handoff / Output Format
- รายงานวิจัย/Persona Document (Markdown) พร้อมสถานะ Evidence กำกับทุกข้อสรุป
- สรุป Insight สั้นสำหรับแผนกที่ร้องขอ (Game_Director, Systems_Designer, Economy_Designer)
