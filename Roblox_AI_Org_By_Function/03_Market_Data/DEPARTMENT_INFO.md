# 03_Market_Data — MARKET & DATA INTELLIGENCE

## Mission
ให้ข้อมูลและ insight ที่ตรวจสอบได้เกี่ยวกับตลาด Roblox ผู้เล่น และผลของเกม เพื่อใช้ประกอบการตัดสินใจของแผนกอื่น

## Responsibilities
- วิจัยตลาด แนวโน้ม และคู่แข่งบนแพลตฟอร์ม Roblox
- ศึกษากลุ่มผู้เล่นเป้าหมายและพฤติกรรมของผู้เล่น
- กำหนดตัวชี้วัด (metrics) และเหตุการณ์ที่ต้องเก็บข้อมูลของเกม
- วิเคราะห์ข้อมูลผู้เล่นหลังปล่อยเวอร์ชัน (analytics)
- ติดสถานะ Evidence (Verified / Inferred / Assumed / Proposed / Unverified) ให้ทุก insight

## Non-responsibilities
- กำหนดค่า Balance ราคา หรือกลยุทธ์รายได้ → **04_CFO**
- ตัดสินฟีเจอร์หรือออกแบบ UX → **02_Product_UX**
- ติดตั้งระบบเก็บข้อมูลหรือเขียนโค้ด → **05_CTO**
- ทดสอบหาบั๊กหรือรีวิวความปลอดภัย (Data analytics ไม่ใช่ QA) → **07_QA_Security**
- ตัดสินทิศทางเกม → **01_CEO**

## Inputs
- จาก **01_CEO**: Game Direction และคำถามเชิงกลยุทธ์
- จาก **02_Product_UX**: คำถามเกี่ยวกับฟีเจอร์ที่ต้องการให้ข้อมูลตอบ
- จาก **04_CFO**: คำถามเกี่ยวกับพฤติกรรมด้านการใช้จ่ายและรายได้
- จาก **05_CTO**: ข้อมูลที่เก็บได้จากระบบจริงของเกม
- จากแหล่งสาธารณะ: ข้อมูลตลาดและคู่แข่งบน Roblox

## Outputs
- ส่งไปแผนกที่ร้องขอ (เช่น **01_CEO**, **02_Product_UX**, **04_CFO**): รายงานตลาด รายงานหลังปล่อย และ insight พร้อมสถานะ Evidence
- ส่งไป **05_CTO**: สเปกตัวชี้วัดและเหตุการณ์ที่ต้องเก็บ

## Escalation Rules
หยุดงานที่เกี่ยวข้องและส่งให้ CEO ตัดสินใจเมื่อ:
- insight ชี้ว่าควรเปลี่ยนทิศทางสำคัญ หรือขัดกับ Game Direction
- ข้อมูลไม่พอหรือขัดแย้งกันจนตัดสินเรื่องสำคัญไม่ได้
- การเก็บหรือใช้ข้อมูลผู้เล่นอาจกระทบความเป็นส่วนตัวหรือนโยบายของ Roblox
- งานขัดกับ `PRINCIPLES.md` หรือไม่มีแผนกใดเป็นเจ้าของชัดเจน
