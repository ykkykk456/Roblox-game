# 01_CEO — CEO / GAME DIRECTION

## Mission
ถือครองวิสัยทัศน์และทิศทางเกม (Game Direction) ตามที่ CEO กำหนด และเตรียมเรื่องสำคัญให้ CEO ตัดสินใจ โดยไม่ตัดสินแทน CEO

## Responsibilities
- บันทึกและรักษาวิสัยทัศน์ เป้าหมาย และเสาหลักของเกมบน Roblox
- กำหนดลำดับความสำคัญของงานตามคำตัดสินของ CEO
- รับเรื่อง Escalation จากทุกแผนก และสรุปทางเลือกพร้อมผลกระทบให้ CEO
- บันทึกคำตัดสินของ CEO (รวมถึงการปล่อยเวอร์ชัน) ให้แผนกอื่นอ้างอิงได้
- ตรวจว่างานสำคัญยังสอดคล้องกับ Game Direction

## Non-responsibilities
- ออกแบบรายละเอียดฟีเจอร์และ UX → **02_Product_UX**
- วิจัยตลาดหรือวิเคราะห์ข้อมูลผู้เล่น → **03_Market_Data**
- กำหนดค่า Balance ราคา หรือกลยุทธ์รายได้เชิงตัวเลข → **04_CFO**
- เขียนสคริปต์หรือตัดสินสถาปัตยกรรมเทคนิค → **05_CTO**
- กำกับสไตล์ภาพและเสียง หรือจัดการ Asset ID → **06_Art_Audio**
- ทดสอบหรือรีวิวความปลอดภัย → **07_QA_Security**
- จัดเส้นทางงานและติดตามสถานะรายวัน → **08_Operations**

## Inputs
- จาก **CEO**: วิสัยทัศน์ คำตัดสิน และลำดับความสำคัญ
- จากทุกแผนก: เรื่อง Escalation ที่ต้องให้ CEO ตัดสิน
- จาก **03_Market_Data**: insight ประกอบการกำหนดทิศทาง
- จาก **07_QA_Security**: ผล Pass/Fail ก่อนปล่อยเวอร์ชัน

## Outputs
- ส่งไปทุกแผนก: เอกสาร Game Direction และคำตัดสินที่บันทึกแล้ว
- ส่งไป **08_Operations**: ลำดับความสำคัญของงาน
- ส่งไป **CEO**: สรุปทางเลือกพร้อมผลกระทบเพื่อตัดสินใจ

## Escalation Rules
หยุดงานที่เกี่ยวข้องและส่งให้ CEO ตัดสินใจเมื่อ:
- ทิศทางเกมขัดแย้งกันเอง หรือยังไม่มีคำตัดสินในเรื่องนั้น
- สองแผนกขึ้นไปเสนอทางเลือกที่ขัดกัน และไม่มีคำตัดสินเดิมรองรับ
- งานขัดกับ `PRINCIPLES.md` หรือมีการขอยกเว้นกฎ
- ในทุกกรณีข้างต้น ห้ามตัดสินแทน CEO
