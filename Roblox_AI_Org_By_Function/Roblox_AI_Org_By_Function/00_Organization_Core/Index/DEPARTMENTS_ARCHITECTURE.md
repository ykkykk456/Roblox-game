# DEPARTMENTS ARCHITECTURE — สถาปัตยกรรมแผนก

**โครงการ:** Roblox AI Development Organization
**สถานะ:** Phase 1 — Top Level Departments
**Progressive Context:** `DEPARTMENT_INFO.md` ของแต่ละแผนกคือ **Level 2 (Department Context)** — โหลดเฉพาะแผนกที่งานเกี่ยวข้อง

> เป้าหมาย: ทุกงานมี **เจ้าของเดียว** และไม่ทำงานทับซ้อนกัน
> Skills เฉพาะทางไม่อยู่ในระดับนี้ (กำหนดใน Phase 3)

## 1. ภาพรวม 8 แผนก

| 8 | `08_Operations` | Operations & Routing | การจัดเส้นทางงาน ตรวจ Handoff ติดตามสถานะ และกำหนดการ |

## 2. เส้นแบ่งของคู่แผนกที่มักทับซ้อน

| คู่แผนก | เส้นแบ่ง |
|---|---|
| Product ↔ CTO | `02` กำหนด "ทำอะไร / ผู้เล่นสัมผัสอย่างไร" (สเปก) — `05` กำหนด "ทำอย่างไรเชิงเทคนิค" และลงมือสร้าง · `02` ห้ามเขียนสคริปต์ · `05` ห้ามแก้สเปกฟีเจอร์เอง |
| QA ↔ Market_Data | `07` ตรวจว่าระบบทำงานถูกและปลอดภัยก่อนปล่อย — `03` วิเคราะห์ว่าผู้เล่นและตลาดเป็นอย่างไร (analytics) · แยกกันเด็ดขาด |
| QA ↔ CTO | `05` สร้างและแก้ไข — `07` ตรวจและรายงาน · ห้ามอนุมัติงานของตัวเอง |
| CFO ↔ Market_Data | `03` ให้ข้อมูลและ insight — `04` ตัดสินตัวเลขเศรษฐกิจและราคา |
| CFO ↔ Product | `02` ออกแบบประสบการณ์ของฟีเจอร์ — `04` กำหนดตัวเลขและราคา · ตกลงกันไม่ได้ → ส่งให้ CEO |
| UI: Product ↔ Art ↔ CTO | `02` โครงหน้าจอและ flow — `06` หน้าตาและ Asset ID — `05` ประกอบและทำให้ทำงานในเอนจิน |
| CEO ↔ Operations | `01` ตัดสินลำดับความสำคัญ — `08` จัดเส้นทางและกำหนดการตามลำดับนั้น |

## 3. กฎร่วมของทุกแผนก

1. งานหนึ่งชิ้นมีเจ้าของเดียว ตามคอลัมน์ "เป็นเจ้าของ" ในหัวข้อ 1
2. ห้ามทำงานที่อยู่ใน Non-responsibilities ของแผนกตน — ส่งต่อด้วย Department Handoff Format
3. ทุกแผนกอยู่ภายใต้ `PRINCIPLES.md`: Server Authority, Data Safety, Evidence System และห้ามใช้ MCP
4. Escalation: หยุดงานที่เกี่ยวข้อง แล้วส่งให้ CEO ตัดสิน โดย `01_CEO` เตรียมสรุปทางเลือก `[Proposed]`
5. พบงานทับซ้อนหรืองานที่ไม่มีเจ้าของ → แจ้ง `08_Operations`

## 4. Interpretation Notes `[Proposed]`

- `01_CEO` คือหน่วยที่ถือครอง Game Direction และเตรียมเรื่องให้ CEO ตัดสิน การตัดสินขั้นสุดท้ายยังเป็นของ CEO ตาม `ROLES.md`
- การเผยแพร่เวอร์ชัน: `05` ดำเนินการเชิงเทคนิคหลัง `07` ให้ผล Pass และ CEO ตัดสินให้ปล่อย ส่วน `08` ประสานกำหนดการ
- การแบ่งงาน UI เป็นไปตามแถว "UI" ในหัวข้อ 2
